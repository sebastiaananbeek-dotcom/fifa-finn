# FIFA Finn

De 50 pro skills voor EA SPORTS FC 27, voor spelers in Divisie 1. Met PlayStation knoppen, een video per skill en uitleg hoe je elke skill traint.

**Bekijk de app:** https://sebastiaananbeek-dotcom.github.io/fifa-finn/

## Wat zit erin

* 50 skills als speelkaarten: Top 10, goud en zilver
* Per skill de knoppen, waarom hij belangrijk is, hoe je hem traint en een pro tip
* Een videoknop die YouTube opent met tutorials voor die skill
* Vink aan wat je beheerst en stijg van Divisie 10 naar Elite

De app is één bestand: `index.html`. Er is geen installatie nodig.

FIFA Finn is een eigen app en hoort niet bij EA SPORTS.
